# Image manifest

Every placeholder in the HTML expects a file at this exact path,
relative to the site folder: `images/<filename>`.

Download each image from Adobe Portfolio (in the order it appears
on that page) and save it under `images/` using the filename below.
The `.jpg` extension is just a placeholder — if the file you save is
actually a `.png` or `.gif`, keep that extension and update the
matching `src="images/..."` attribute in the HTML to match (or just
rename the downloaded file to end in `.jpg` — browsers display images
by their real content, not the extension, so this works fine too).
